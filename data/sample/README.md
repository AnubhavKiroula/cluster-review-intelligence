# SYNTHETIC sample data

`synthetic_reviews.csv` is **SYNTHETIC** — generated by `src/cri/generate.py`
(`seed=42`). It contains fictional properties (`Property A`…`Property L`) and no
real reviews or personal data.

Regenerate with:

```bash
python -m cri.generate --out data/sample/synthetic_reviews.csv
```

Two patterns are injected into the review text as test ground truth:

1. **Property F** food quality collapses from **2025-06** (property-specific).
2. **Every December**, heating/room complaints spike across **all** properties
   (market-wide).

Real, team-provided exports belong in `data/raw/` (gitignored) and must follow
[`docs/data_schema.md`](../../docs/data_schema.md).

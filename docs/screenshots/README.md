# Web app screenshots (SYNTHETIC data)

Real screenshots of the Next.js app (`web/`) on the **SYNTHETIC** review sample
(seed 42); the SYNTHETIC banner is visible on every page. The explorer shot also needs
the API (`cri.server`) for live classification.

| File | Page |
|---|---|
| `demo_SYNTHETIC.gif` | The clip below as an animated GIF (1280×720, 15fps, 0.19 MB). This is what the README embeds: GitHub strips `<video>` from Markdown, and a link to a repo-hosted `.mp4` renders as a plain link, so a GIF is the only form that plays in the page itself |
| `demo_SYNTHETIC.mp4` | 20s silent overview: the 2025-06 Food changepoint at Property F, the market-adjusted split (−1.21 / +0.01 / −1.22), the three kinds of verdict, and a Hinglish review splitting into two aspects. Full quality, with a scrubber |
| `demo_poster_SYNTHETIC.jpg` | Poster frame for the clip above (the market-adjusted split), also baked as its first frame |
| `property_view_SYNTHETIC.png` | Property F: "Fix Food first since 2025-06", whose problem it is, scorecard vs cluster with 95% intervals, trend with the detected changepoint |
| `market_quadrant_SYNTHETIC.png` | Market-wide vs property-specific, with the worst market-wide aspect |
| `fix_check_SYNTHETIC.png` | "Did my fix work?" before/after vs the market |
| `review_explorer_SYNTHETIC.png` | "Try your own review" on a Hinglish example |

`demo_SYNTHETIC.mp4` is the one asset here **not** regenerated by a committed script. It
is rendered from a hand-authored HTML composition (this project's palette, type and
`ChangeSplit` component, animated with GSAP) that is kept outside the repository; its
figures are read from `web/public/data/cluster.synthetic.json`, so they move only when
the snapshot does. The poster is baked as the clip's first frame so every player shows
it when idle. The PNGs below are reproducible:

Re-capture after UI changes (needs `pip install playwright==1.58.0`, not a project
dependency, and an installed Edge or Chrome):

```bash
uvicorn cri.server:app --port 8000
cd web && npm run build && python -m http.server 3000 --directory out
python scripts/capture_screenshots.py
```

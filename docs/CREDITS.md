### Why the demo clip has no audio

A version of `demo_SYNTHETIC.mp4` with a music bed and interface sound effects exists
outside this repository. It is not committed here, and the committed clip has its audio
track removed rather than muted.

The music came from a bundled asset set whose own notes say its exact licence terms must
be verified before redistribution. Verifying them is not the same as assuming them, so
under the rule above the track cannot be committed. The same reasoning the GSAP note
below applies to code applies here to media: the repository does not redistribute an
asset whose terms are unconfirmed. GitHub's player starts muted in any case, so the
README loses nothing.

If the terms are confirmed later, the audio version can be swapped in and recorded here
with its source and licence. The fonts the clip renders with (Literata, IBM Plex Sans)
are the SIL OFL 1.1 faces already listed above, self-hosted from this project's own
build output.

## Data

All bundled data in `data/sample/` and `data/locations/` is **SYNTHETIC**, produced by
`src/cri/generate.py`. It depicts fictional properties and contains no real
reviews or personal data.

The travel layer removed on 2026-10-13 used sourced facts (DoPT holidays, Wikidata,
HPTDC and NIC district distances, UTDB arrivals, India GHG Program and UK DESNZ
emission factors) and SYNTHETIC profiles; they and their credits remain at the git
tag `travel-layer-v1`.

Training data for the shipped sentiment model (`src/cri/resources/models/`), both
CC BY 4.0 and attributed in its model card:

- Patwa et al., *SemEval-2020 Task 9: Overview of Sentiment Analysis of Code-Mixed
  Tweets* (SentiMix), Zenodo doi:10.5281/zenodo.3974927.
- *Hinglish YouTube Sentiments* dataset, shae2977 on Hugging Face.

A locally trained model also used the Kaggle dataset *Uttarakhand Hotel Reviews
(India)* by orionpax00. Neither that data nor that model is distributed.

## Software

Built with Python, NumPy, pandas, PyYAML, Matplotlib, FastAPI, Uvicorn and
scikit-learn (training only) (see `pyproject.toml` for pinned versions), and Next.js,
React, Plotly.js and GSAP (see `web/package.json`).

GSAP 3.13.0 animates the web app (`web/lib/motion.ts`). Unlike every other dependency
here it is **not** under an OSI-approved licence: its `package.json` states
`Standard 'no charge' license: https://gsap.com/standard-license.` It is installed from
npm and is not vendored into this repository, so nothing proprietary is redistributed
here, and this project is free to read and use. If the licence is a problem for a
downstream user, `web/lib/motion.ts` is the only file that imports it and it is loaded
dynamically, so the whole animation layer can be replaced in one file without touching
any page. GitHub Actions used: `actions/checkout`,
`actions/setup-python`, `actions/setup-node`, `actions/upload-artifact`, `ossf/scorecard-action`,
`github/codeql-action`, and `step-security/harden-runner` (all pinned by commit
SHA).
